To-Do List App

A simple and interactive To-Do List application built using React.js. This project helps users organize their daily tasks and manage their activities through a clean and user-friendly interface.

Features

- Add new tasks to your to-do list.
- View and manage your tasks.
- Mark tasks as completed.
- Delete tasks when they are no longer needed.
- Simple and user-friendly interface.

Tech Stack

- React.js
- JavaScript
- HTML5
- CSS3
- Vite

Getting Started

Follow these steps to run the project locally.

1. Clone the repository

git clone https://github.com/karanveersingh-15/To-do-list.git

2. Navigate to the project folder

cd To-do-list

3. Install dependencies

npm install

4. Start the development server

npm run dev

Open the local URL displayed in your terminal to view the application.
